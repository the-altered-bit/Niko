      1Meet Niko

      Niko is a general-purpose programming language whose programs read like plain instructions. You can build games, tools, calculators, and data programs with it, the same things you would build with Python, but with fewer symbols and friendlier messages.

      Four ideas sit at the heart of Niko:

      • Words over symbols. You write is at least instead of >=, and put x in list instead of list.append(x).
      • One clear way to do each job, so there is less to memorize.
      • Helpful errors. Niko tells you what went wrong in everyday language and points to the line.
      • Real power underneath. On the desktop, Niko turns into Python, so every Python library is available to you.

      A Niko program is a plain text file that ends in .niko. Here is a complete one:

      ask "What is your name? " into name
say "Hello,", name + "!"
repeat 3 times:
    say "Niko is easy."
      What is your name? Ana
Hello, Ana!
Niko is easy.
Niko is easy.
Niko is easy.

      Read it out loud and you already understand it. That is the goal.

      3Set up and run your first file

      There are two ways to run Niko. Start with the first one, it needs nothing installed.

      Way 1: the Niko IDE (in your browser)

      1. Open the Niko IDE: https://claude.ai/artifact/AJLUh6jy95WUV7M5gruBJa
      2. Type or paste a program into the editor.
      3. Press the green Run button (or Ctrl+Enter). Output appears in the panel at the bottom.
      4. When your program asks a question, type the answer in the output panel and press Enter.

      Your files save automatically in your browser. The Explorer lists your files and seven example programs, and Ctrl+Shift+P opens a command palette for everything else.

      Way 2: on your computer with niko.py

      1. Install Python 3.8 or newer from python.org.
      2. Save niko.py in a folder, and save your program in the same folder as hello.niko.
      3. Open a terminal in that folder and run: python niko.py hello.niko
      4. Add --show to see the Python that Niko creates: python niko.py hello.niko --show
      5. Run python niko.py with no file to open the REPL (next chapter).

      4Try things live: the REPL

      A REPL (read, evaluate, print, loop) lets you type one line and see the answer right away, with nothing to save or compile. It is the best way to experiment.

      • In the IDE: open the REPL tab in the bottom panel, or press Ctrl+Shift+P and choose "Open the REPL".
      • On the desktop: run python niko.py with no file name.

      Here is a short session. Lines starting with niko> are what you type.

      niko> set x to 5
niko> x * 2
10
niko> "hi" + " there"
"hi there"
niko> to double with n:
...       give back n * 2
...
niko> double(x)
10
niko> set score to 3
niko> scor
Oops: I don't know what "scor" is. Did you mean "score"?

      How it works

      • Type an expression, such as x * 2, and Niko shows its value.
      • Variables and functions you create stay for the whole session.
      • A line that ends with : continues on the next line. Type the indented lines, then press Enter on an empty line to run the block.
      • A mistake never ends the session. Niko explains it and waits for your next line.
      • Type help for tips. On the desktop, exit (or Ctrl+D) leaves. In the IDE, clear wipes the screen and reset forgets everything.
      Tip Try a new idea in the REPL first. When it works, copy it into a .niko file.

      5Your first program: say

      say shows something on the screen. Text goes inside double quotes. You can say several things in one line by separating them with commas, and Niko puts a space between them.

      say "Hello, world!"
say "I am", 12, "years old"
say
say "That was an empty line above."
      Hello, world!
I am 12 years old

That was an empty line above.

      Each line is one instruction. Niko runs them from top to bottom.

      Try it Change the text, add a line, delete a line, and press Run again. Breaking things on purpose is the fastest way to learn.

      6Comments

      A comment is a note for humans. Niko ignores everything after a #.

      # This whole line is a note.
say "Hi"   # a note at the end of a line
say "Not a # note, because it is inside quotes"
      Hi
Not a # note, because it is inside quotes

      Use comments to explain why you did something, not to repeat what the line already says.

      8Variables

      A variable is a name for a value, like a labeled box. Create or change one with set. Make a number bigger with add, and smaller with take.

      set age to 12

      Naming rules

      • Use letters, digits, and underscores: high_score, player2.
      • Start with a letter. No spaces. Capital letters count: Score and score are different names.
      • Pick names that say what is inside: total_price beats x.
      • Do not reuse Niko words (set, say, to, is, if, of...) or helper names (text, sum, max, min, sorted, trim, replace, today, pi...). The full list is in the A to Z reference.
      • Also avoid class, def, function, import, let, new, return, and var.
      Careful Using a name before you set it gives: I don't know what "score" is. Did you "set" it first?

      11Asking questions

      ask waits for the person to type something and stores it in a variable. Use ask number when you need a number. It asks again until the answer really is a number.

      18Errors and how to fix them

      Every programmer sees errors all the time. They are clues. Niko names the line and explains the problem.

      set total to 10
say totl
      Oops on line 2: I don't know what "totl" is. Did you mean "total"?
      MessageWhat it meansHow to fix it
      I don't know what "x" isYou used a name you never created, or misspelled itCheck the spelling, and set it before using it
      That position isn't in the listThe list is shorter than that, or you used item 0Positions go from 1 to length of the list
      You mixed text and numbersTried to add text and a number (desktop)Use text(number) to turn it into text
      "otherwise" needs an "if" right above itotherwise is not lined up with an ifGive otherwise the same indentation as its if
      This line doesn't make sense to meA typo, an unclosed bracket or quote, or a missing colonRead the line slowly, check : " ( [
      You can't divide by zeroA division had 0 underneathCheck the number you divide by (desktop)
      I couldn't find the file "x"You tried to read a file that was never writtenCheck the name, or write_file it first
      I can't turn "abc" into a numbernumber(...) was given something that is not a numberCheck what the text really contains

      Look at the first row of that table. When a name is close to one you already made, or to a helper like upper, Niko adds a hint: Did you mean "total"?

      A debugging routine that works

      1. Read the message. It names the line.
      2. Look at that line and the one above it.
      3. Add say lines to see what your variables hold.
      4. Shrink the program until the problem is tiny.
      5. Change one thing, run, repeat.

      20How to learn Niko: a 4-week plan

      Twenty to thirty minutes a day beats one long weekend. Every session follows the same rhythm: read a little, type the examples yourself (do not paste), change them, then solve one exercise.

      Five habits of people who learn fast

      • Type it yourself. Your fingers learn what your eyes skip.
      • Run early and often. Run after every two or three lines.
      • Change one thing at a time, then predict what will happen before you run it.
      • Read every error. It is usually right.
      • Build small things you care about. A quiz about your favorite show teaches more than a textbook exercise.

      23Style guide

      • Indent with 4 spaces. Never mix tabs and spaces.
      • Use lower_case_with_underscores for names. Make them descriptive.
      • One instruction per line.
      • Leave a blank line between functions and between big parts of a program.
      • Comment the why, not the what.
      • Keep functions short. If you can't name it in a few words, it is doing too much.
      • Put your functions at the top, and the part that runs them at the bottom.

      25Join in: help and community

      Niko is new, so its community is something we build together. This chapter says where to find help today and how anyone can help the language grow.

      Where to get help right now

      • Error messages. They name the line and often suggest the fix. Read them first.
      • The REPL. Try the tricky line by itself (chapter 4).
      • The examples. The IDE Explorer has seven programs. Open one, change it, break it, fix it.
      • This guide. Use the A to Z reference (chapter 26) when you forget a word.
      • The --show flag. It prints the Python that a program becomes, so you can see what Niko really did.

      How to ask for help well

      A good question gets a good answer fast. Include these four things:

      1. What you wanted to happen.
      2. What happened instead, including the exact error message.
      3. The smallest program that shows the problem (paste it as text).
      4. Whether you used the IDE or niko.py.
      I want to add up a list of prices.
Instead I get: I don't know what "prices" is. Did you mean "price"?

set price to [4, 5, 6]
say sum(prices)

I am using the IDE.

      Share your work

      Niko programs are plain text, so sharing is easy: paste the code into a message, or save the .niko file. Add a comment at the top that says what the program does and who wrote it.

      Ideas to grow the community

      • Home for the code: a public repository holding niko.py, the IDE, this guide, and the examples, with a README that shows the two-line temperature example first.
      • A gallery: a folder of small programs from learners, each with a comment header. Nothing motivates like seeing what others built.
      • Weekly challenge: one small problem a week, such as "write a program that prints a multiplication table for any number". Post solutions in different styles.
      • Beginner-friendly tasks: label small jobs (a new helper, a better error message, a new example) so newcomers can contribute.
      • Short tutorials and videos: one idea each, five minutes, ending with a program the viewer can run.
      • A friendly rule: every question is welcome, and every answer explains why, not only what.

      Adding a helper to Niko

      Most helpers are one line long. In niko.py, add an entry to the LIB table. In the IDE, add a matching function to LIB in the page. Then add the word to the A to Z reference. Keep the same name and behavior in both.

      27How Niko works: the language rules

      This is the short formal description of the language.

      Program shape

      • A program is lines of text, saved in a file ending with .niko.
      • One instruction per line. Blocks are the lines indented more than the line above, and that line ends with :.
      • Everything is case-sensitive. Keywords are lowercase.
      • Comments start with # and run to the end of the line.

      The instructions

      FormWhat it does
      set NAME to VALUECreate or change a variable
      set item N of LIST to VALUEChange a list position
      set RECORD["key"] to VALUEChange or add a record label
      add VALUE to NAME / take VALUE from NAMEArithmetic on a variable
      put VALUE in LIST / remove VALUE from LISTAdd to or take from a list
      say VALUE, VALUE, ...Print values separated by spaces
      ask TEXT into NAME / ask number TEXT into NAMERead input
      if C: / otherwise if C: / otherwise:Choose
      repeat N times: / repeat forever:Repeat
      for each NAME in LIST:Go through a list, text, or numbers A to B
      while C:Repeat while true
      stop / skipLeave the loop / next round
      to NAME with A, B: / to NAME:Define a function
      give back VALUEReturn from a function
      use NAMEImport a Python library (desktop only)
      any other lineAn expression, such as calling a function: greet("Sam")

      Expressions

      • Math: + - * / % ** and parentheses. * / % go before + -, and ** goes first.
      • Comparisons in words: is, is not, is bigger than, is smaller than, is at least, is at most, is in.
      • Logic: not, then and, then or. Values yes, no, nothing.
      • Position and size: item N of X, length of X, numbers A to B, random A to B.
      • Calls: name(arguments).

      Rules worth remembering

      • Positions in lists and text start at 1.
      • Functions can read and change variables made outside them. Variables first created inside stay inside.
      • numbers A to B includes both ends and counts down when A is bigger.
      • Reserved words: set add take put remove say ask into number if otherwise repeat times forever for each in while stop skip to with give back use is not and or of from yes no nothing.
      • Built-in helpers are grouped as: numbers, text, lists, files, and time. See chapter 17.

      Two engines, one language

      The browser IDE turns each Niko line into JavaScript. niko.py turns each line into Python. Both follow the same rules, and every example in this guide is checked to print the same result in both.

      28Questions people ask

      Why is instead of =?

      set gives a value to a variable, and is asks a question. Using different words for different jobs avoids a classic beginner mix-up.

      Can I write else?

      No, use otherwise. Niko will tell you if you forget.

      Can I put two instructions on one line?

      No. One line, one instruction.

      How do I do division with no decimals?

      floor(a / b).

      How do I get the last item of a list?

      item length of xs of xs. Or store the length first: set last to length of xs, then item last of xs.

      My program asks but nothing happens on the desktop.

      The program is waiting for you to type. Type your answer in the terminal and press Enter.

      Why does my number look like text?

      ask always returns text. Use ask number, or number("42").

      Can I split a program across files?

      Not yet. Keep each program in one .niko file.

      29Glossary

      Argument
      A value you give to a function when you call it.
      Bug
      A mistake in a program. Finding and fixing bugs is called debugging.
      Comment
      A note for humans that starts with #.
      Condition
      Something that is yes or no, such as age is at least 18.
      Function
      A named block of instructions you can run whenever you like.
      Indentation
      The spaces at the start of a line that show which block it belongs to.
      Input
      What a person types into a program.
      List
      Many values kept in order, starting at position 1.
      Loop
      Instructions that repeat.
      Output
      What a program shows.
      Record
      Labeled values, such as a pet with a name and an age.
      REPL
      A place where you type one line at a time and see the result right away.
      Run
      Ask the computer to follow your program.
      Standard library
      The helpers that come with the language, like trim and read_file.
      Text
      Letters inside quotes. Programmers also call it a string.
      Value
      One piece of data: a number, text, yes/no, nothing, a list, or a record.
      Variable
      A name that holds a value.
